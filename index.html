PRIVACY FIRST

ก่อนเริ่มแบบสำรวจ

แบบสอบถามมีข้อมูลด้านสุขภาพและพฤติกรรมส่วนบุคคล โปรดให้ลูกค้าอ่านรายละเอียดและยินยอมก่อนกรอกข้อมูล

การใช้ข้อมูลในต้นแบบนี้
  • เพื่อประเมินความต้องการความคุ้มครองและจัดทำสรุปผลสำหรับลูกค้า
  • ข้อมูลประมวลผลบนอุปกรณ์ที่เปิดเว็บนี้ ไม่มีการส่งไปยังเซิร์ฟเวอร์ของแอป
  • การบันทึกลงเบราว์เซอร์เป็นทางเลือก หากไม่เปิดใช้ ข้อมูลจะไม่ถูกบันทึกค้างไว้ในเครื่องโดยแอป
  • ผู้กรอกสามารถล้างข้อมูลทั้งหมดได้ทุกเมื่อ และควรเก็บไฟล์ JSON ที่ส่งออกไว้ในที่ปลอดภัย
โหมด GitHub Pages นี้เป็นระบบทดลองเท่านั้น โปรดใช้ข้อมูลสมมติ ไม่ใช้เก็บข้อมูลลูกค้าจริง หากต้องรับข้อมูลสุขภาพจริงต้องใช้ Backend/Cloud ที่มีมาตรการรักษาความปลอดภัยและ PDPA
